# Sense Energy for Homey

Monitor your home energy usage, solar production, and real-time power with Sense Energy Monitor in Homey.

## Features

- **Real-Time Power Monitoring**: Track live home power consumption, solar production, grid draw, and net power.
- **Polling & WebSockets**: Automatic updates via Sense API polling and real-time WebSocket connection.
- **Easy Pairing**: Securely connect using your Sense account credentials.
